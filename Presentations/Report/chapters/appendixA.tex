\chapter{\uppercase{Phase 1 Flow}}
The Phase~1 workflow of the group project can be summarized as:
\begin{enumerate}
	\item Base paper study.
	\item Literature review.
	\item Research gap identification.
	\item Problem statement formulation.
	\item Objective identification.
	\item System requirement identification.
	\item Proposed architecture planning.
	\item Financial calculation planning.
	\item Safety and feasibility planning.
	\item Risk profiling planning.
	\item Recommendation engine planning.
	\item Dynamic allocation planning.
	\item Mobile application planning.
	\item Phase~2 development planning.
\end{enumerate}
